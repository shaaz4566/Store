SZC STORE — FIREBASE LIVE CATALOGUE

Products and category photos are stored in Firebase.
Do not replace index.html after adding products.

Admin:
- Google sign-in
- Product photo upload -> Firebase Storage -> Firestore product URL
- Category photo upload -> Firebase Storage -> Firestore settings
- Categories and features are managed in Firestore

Customer:
- index.html loads the live catalogue from Firebase
- New products/photos appear after the Firebase data loads

Deploy storage.rules to Firebase Storage Rules and enable Firebase Storage.
